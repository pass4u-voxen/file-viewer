내 컴퓨터 사양 정리

윈도우에 원래 있는 DirectX 진단 도구(dxdiag) 파일을 넣으면, 카페에 올리기 좋은 사양 글로 바꿔 드려요.

🔒 파일은 서버로 올라가지 않아요. 컴퓨터 이름·사용자 이름 같은 정보는 글에 넣지 않아요. 방문 수만 셀 뿐, 파일 내용은 보내지 않아요.

  2. "디지털 서명을 확인할까요?" 창이 뜨면 예를 눌러요.
  3. 창 아래 초록 막대가 끝날 때까지 기다린 뒤 모든 정보 저장을 눌러요.
  4. 바탕 화면에 저장해요. 파일 이름은 DxDiag.txt 예요.

dxdiag는 마이크로소프트가 윈도우에 넣어 둔 기본 도구예요. 따로 설치하거나 명령어를 붙여넣을 필요가 없어요.
